# Tamakloe: Agent IA et Pipeline de Traitement de Données

##  À propos de ce projet
Ce projet a été développé dans le cadre de mon stage de recherche au sein du **GATE (Saint-Étienne School of Economics)**. 
L'objectif est de combiner le traitement de données structurées et l'Intelligence Artificielle pour analyser et modéliser des préférences et des comportements économiques.

##   Outils et Langages
* **Langage :** Python
* **Modèles de Langage (LLM) :** Mistral 7B (Hugging Face)
* **Déploiement local :** Ollama
* **Optimisation / Fine-Tuning :** LoRA
* **Interface Utilisateur :** Gradio
* **Data :** Manipulation de fichiers JSON et structuration de données

##  Fonction principales
1. **Traitement de données :** Ingestion et nettoyage de bases de données JSON complexes.
2. **Agent IA :** Interfaçage avec un modèle Mistral 7B exécuté localement via Ollama.
3. **Interface interactive :** Création d'une application web avec Gradio permettant d'interagir facilement avec le modèle et les résultats de l'analyse.
4. **Fine-Tuning :** Mise en place d'un pipeline d'entraînement LoRA pour adapter le modèle à des tâches spécifiques.
